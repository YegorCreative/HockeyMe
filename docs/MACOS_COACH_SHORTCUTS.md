# Forge Coach Keyboard Shortcuts

Forge Coach uses standard macOS commands and preserves normal system menu
behavior.

| Shortcut | Action |
| --- | --- |
| Command-N | Create the primary object in Programming, Testing, or Teams |
| Command-F | Focus search in the current searchable section |
| Command-S | Save supported in-memory edits |
| Command-D | Duplicate the selected program |
| Command-1 | Dashboard |
| Command-2 | Athletes |
| Command-3 | Teams |
| Command-4 | Programming |
| Command-5 | Testing |
| Command-6 | Analytics |
| Command-7 | Organization |
| Command-8 | Settings |
| Return or double-click | Open the selected table item where supported |

Destructive operations remain behind context-menu actions and native
confirmation dialogs. Full Keyboard Access can traverse the sidebar, tables,
toolbar, filters, inspectors, and forms without a pointing device.
