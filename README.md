# Forge Fitness

Forge Fitness is a modern athlete-development platform for hockey coaches and athletes. It is intended to bring training programs, performance tracking, analytics, and coaching workflows into one cohesive product.

## Repository structure

- `ios/` — native iOS application
- `web/` — web application
- `backend/` — backend services and infrastructure
- `docs/` — product and technical documentation
- `assets/` — shared project assets
